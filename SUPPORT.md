# Support / サポート

## 日本語

以下の内容は GitHub Issues から報告してください。

- バグ
- 誤検出 / 見逃し
- チェックしてほしいLottie書き出し制限
- 日本語 / 英語の表現に関する問題
- 改善要望

バグ報告には、可能であれば以下を含めてください。

- Figma Desktopのバージョン
- プラグインのバージョン
- 問題が起きたレイヤー / エフェクトの簡単な説明
- 機密情報を含まない場合のみスクリーンショット

**機密情報を含むFigmaファイルやスクリーンショットを公開Issueへアップロードしないでください。**

## English

Please use GitHub Issues for:

- Bugs
- False positives / false negatives
- Lottie export limitations you would like checked
- Japanese/English wording issues
- Improvement requests

When reporting a bug, include when possible:

- Figma Desktop version
- Plugin version
- A minimal description of the affected layer/effect
- A screenshot only if it contains no confidential design data

**Do not upload confidential Figma files or screenshots to a public issue.**
