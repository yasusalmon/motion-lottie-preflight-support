# Changelog

## 0.1.0 — Free pilot candidate

- Initial public-pilot candidate.
- Detect unsupported video paints.
- Detect angular/conic gradients and distinguish static vs animated severity.
- Detect shader paints and shader effects.
- Warn on animated drop shadow, noise, and glass effects with partial Lottie support.
- Ignore hidden nodes and invisible paints.
- Show exact layer path and affected property.
- Jump to the affected layer from a finding.
- Support multiple selected layers.
- Add Japanese and English UI.
- Add visible scan-state feedback.
- Declare no network access in the plugin manifest.
- Keep operation read-only with no automatic file changes.
