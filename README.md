# Motion Lottie Preflight — Support

Support and public documentation for **Motion Lottie Preflight**, a read-only Figma plugin that checks selected Figma Motion layers for known native Lottie export limitations before export.

## What it does

- Flags known unsupported or partially supported Motion/Lottie features.
- Identifies the affected Figma layer/property.
- Lets you jump to the affected layer.
- Runs locally in Figma.
- Makes no network requests and does not modify design files.
- Supports Japanese and English UI.

## Important

This plugin is an advisory preflight checker, not a guarantee of compatibility with every Lottie player. Always test final exported assets in the intended production runtime.
