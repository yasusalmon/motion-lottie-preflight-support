# Security / セキュリティ

Motion Lottie Preflight is designed to operate locally inside Figma.

- No backend service
- No network requests
- No user authentication
- No Figma-derived data stored externally
- No automatic modification of design files

## Reporting a security issue

If you believe you found a security issue, please do **not** post confidential design data, tokens, credentials, or other sensitive information in a public Issue.

Open a minimal public Issue describing the nature of the problem without sensitive details so a private reporting path can be arranged if necessary.

## セキュリティ上の問題を報告する場合

公開Issueには、機密デザインデータ、トークン、認証情報、その他のセンシティブな情報を投稿しないでください。

必要に応じて非公開の報告経路を案内できるよう、まずは機密情報を含めずに問題の概要のみをIssueへ記載してください。
