# Privacy Policy / プライバシーポリシー

Last updated: 2026-10-07

## 日本語

Motion Lottie Preflight は、ユーザーが選択したFigma内のレイヤー情報を、その場で読み取り、既知のLottie書き出し制限を確認するためのプラグインです。

### 取り扱う情報

プラグインは、ユーザーがFigma上で明示的に選択したレイヤーと、その配下の表示レイヤーについて、塗り・線・エフェクト・アニメーションに関する情報を読み取ります。

### 外部送信

- 外部サーバーへの通信を行いません。
- デザインデータを外部へ送信しません。
- 分析データ、利用履歴、個人情報を外部へ送信しません。

### 保存

- Figma APIから読み取ったデータを保存しません。
- アカウント情報や個人情報を収集・保存しません。

### ファイルへの変更

- デザインファイルを変更しません。
- 自動修正を行いません。
- 「該当レイヤーを選択」機能は、Figma上の選択状態と表示位置を変更するだけです。

### 注意事項

本プラグインは書き出し前の補助チェックです。すべてのLottie実装・プレイヤーでの完全な互換性を保証するものではありません。最終成果物は実際の利用先でも確認してください。

## English

Motion Lottie Preflight is a local Figma plugin that reads information from the layers a user explicitly selects in order to check known native Lottie export limitations.

### Data processed

The plugin reads properties of the explicitly selected layers and their visible descendants, including fills, strokes, effects, and relevant animation bindings.

### Network transmission

- The plugin makes no network requests.
- Design data is not uploaded or transmitted to any external server.
- Analytics, usage history, and personal information are not transmitted externally.

### Storage

- The plugin does not store data read or derived from the Figma Plugin API.
- The plugin does not collect or store account information or personal data.

### File changes

- The plugin does not modify the design file.
- It does not apply automatic fixes.
- The “Select layer” action only changes the current Figma selection and viewport so the user can inspect the affected layer.

### Disclaimer

This plugin is an advisory preflight check and does not guarantee compatibility with every Lottie implementation or player. Always test the final exported asset in its intended production environment.
